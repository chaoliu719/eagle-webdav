# 状态窗口、日志与排查

> 读者：使用者，以及需要向开发者反馈问题的人。

## 状态窗口

插件窗口从上到下是：

1. 状态与连接地址（右上角的开关控制服务启停，地址旁有「复制」）
2. 设置
3. 最近连接的设备（按 User-Agent 识别 Finder / Infuse / rclone 等）
4. 最近请求与日志（默认收起）

遇到需要你处理的事（比如 Eagle 在等重复添加确认）会在设置上方出现黄色提示。窗口跟随系统的浅色 / 深色模式；界面语言跟随 Eagle（简体中文 / 繁体中文 / 英文）。

## 窗口里的四种提示

- **Toast**（底部浮出，几秒自动消失）：保存的结果，如「已保存，服务已重启」「已保存，下次启动时生效」「没能保存：…」。
- **横幅**（留到解决）：服务没能启动（可点「改端口」「重试」）、Eagle 版本过低、Eagle 在等你确认「重复添加提示」（可点「忽略」）。这几种同时会用 Eagle 的系统通知提醒你一次，窗口关着也能知道。
- **行内红字**：端口、账号填错时，红字贴在那个字段下面。
- **状态标签**：正在阻止休眠时，「运行中」旁边出现「保持唤醒」；自动发现没能启动时，开关下方有一行黄字。

## 日志

- 服务会把重要的事（启动停止、设置保存、上传删除改名、出错、变慢）记到 `~/Library/Application Support/Eagle/eagle-webdav/logs/` 下，每天一个文件，保留 7 天；普通的浏览和播放不记录。
- 要看更详细的逐条请求，把配置文件 `config.json` 里的 `logLevel` 改成 `debug`，重启服务生效（改回 `info` 即可恢复）。

## 出了问题怎么办

1. 在窗口最下面的「最近请求与日志」里点「复制诊断信息」，直接粘贴给开发者。里面有版本、设置开关、最近的性能和日志；不含密码、账号名和文件内容，资源库路径也会被抹掉。
2. 「打开日志文件夹」可以直接在 Finder 里看原始文件。

## 常见问题

- **连不上**：先看窗口里是否「运行中」、有没有红色或黄色横幅；端口被占用时点「改端口」。局域网设备连不上，确认「谁能访问」选的是「局域网内的设备」，且防火墙允许 Eagle 入站。
- **素材传上去却没出现**：多半是 Eagle 在等你确认「重复添加提示」，见[目录结构与行为差异](library-behavior.md)。
- **没有扩展名的文件上传失败（415）**：Eagle 不识别无扩展名文件，给文件加上扩展名。
- **在 Eagle 里改了东西客户端没变**：客户端下一次请求后最多约 1.5 秒会刷新；Finder 可重新进入目录。

## 已知限制

- Eagle 没有删除文件夹的 API：DELETE 文件夹返回 403。
- 锁是假锁：发令牌，不强制互斥。
- 大资源库（几十万素材）的性能尚未实测；协议层在 20 万条的假数据上列 2 万条的目录约 0.1 秒，真正的耗时取决于 Eagle 自身的查询。「未分类」和「@标签」每次缓存失效后需要重新向 Eagle 查询，大库里首次打开会慢一些。

## 安全建议

- 只在家里的局域网使用：默认只放行回环、10/8、172.16/12、192.168/16、169.254/16 和 IPv6 内网地址的来源；同一来源连续认证失败 10 次会被封禁 10 分钟。
- 要从外网访问，不要直接暴露本服务，在前面加 Caddy 或 Nginx 做 HTTPS 和访问控制。
- 没设管理密码时，能连上服务的任何人都等同管理账号；对局域网开放前请自行决定是否设置密码。
- 服务使用明文 HTTP，账号密码以 Basic 认证传输，只适合可信网络。
