1. 环境信息（R2、R11）

记录 Node 与 Electron 版本、Eagle 版本与 build、Plugin API 上实际存在的方法、资源库路径。只读。

2. WebDAV 抓包服务（R1、R2、R7、R13）

纯内存的 WebDAV 服务，不读写 Eagle 数据。用 Finder、Infuse、rclone 连接它，记录每个请求。关闭本窗口后服务是否继续运行，看 ~/EagleWebdavProbe/heartbeat.log 是否还在增长。

（尚无请求）

3. 写入探针（R3、R4、R5、R6、R8、R9、R12）

会在当前资源库里创建两个以 __webdav_probe_ 开头的文件夹，导入十来个测试素材，改名、改归属、移入回收站。只操作它自己创建的对象，但建议先在一个测试资源库上运行。结束后探针素材会进回收站，两个文件夹需要你在 Eagle 里手动删除。

4. 性能探针（R10，只读）

测量 countAll、getIdsWithModifiedAt、folder.getAll、按文件夹 item.get 的耗时与内存。建议在你的真实大资源库上运行。
