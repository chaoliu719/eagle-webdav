# Eagle WebDAV 使用指南

插件运行后，Eagle 开着的 Mac 会提供 WebDAV 服务，Finder、Infuse、rclone 等客户端可以像访问网盘一样读写 Eagle 资源库。本文按 Eagle 4.0.0 Build 23（macOS）上的实测结果编写；Infuse、iPad 客户端和 Finder 图形界面的拖拽尚未真机测过，已用 rclone、ffmpeg（HTTP 取流）和系统 WebDAV 挂载做了等价验证。

## 安装与首次设置

1. 需要 Eagle 4.0 Build 12 或更高，推荐 Build 23。
2. 在项目目录执行 `npm install` 和 `npm run build`，再在 Eagle 的「开发者选项」里把 `plugin/` 目录作为本地插件加载。它是后台服务插件，随 Eagle 启动。
3. 打开插件窗口：选监听地址（默认仅本机，要给其他设备用就选局域网 IP）、端口（默认 41600）。管理账号没设密码时**不需要认证**，任何访问都等同管理账号；想要认证就设置密码；要去掉已设置的密码，把密码框清空再保存（框里的黑点表示「不修改」）。改完点「保存」，服务会自动重启。
4. macOS 防火墙若弹出提示，允许 Eagle 接受入站连接。
5. 之后只要 Eagle 开着，服务就在；Eagle 退出，服务随之停止；切换资源库时服务会短暂返回 503，随后恢复。

账号密码、端口等配置保存在 `~/Library/Application Support/Eagle/eagle-webdav/config.json`（权限 0600，密码是 scrypt 哈希）。

## 各设备怎么用

| 设备或工具 | 推荐用法 | 注意事项 |
| --- | --- | --- |
| Mac Finder | Command + K，输入 `http://Mac 的 IP:41600/`，填账号密码挂载 | 拖入的文件会导入 Eagle，资源库里是一份副本；改名、移动、复制会同步到 Eagle |
| iPad、iPhone 看影音 | 用 Infuse：在「添加文件源」的发现列表里选这台 Mac，或手动填 `http://Mac 的 IP:41600/`（IP 可在插件窗口「设置 → 监听地址」的下拉框里看到） | 支持 Range 拖进度条；mp4（索引在文件尾或头）、mkv 的跳转读取已用 ffmpeg 验证 |
| iPad、iPhone 管文件 | 用提供文件提供者的第三方 WebDAV App | 「文件」App 的「连接服务器」原生似乎只支持 SMB；局域网地址可用 HTTP |
| rclone 与脚本 | `rclone config` 选 webdav，vendor 选 other；`rclone ls`、`copy`、`check` | 已验证 lsd/ls/copy/check，可按文件夹结构导出备份 |
| Windows | 不建议作主力 | 默认禁用 HTTP 上的 Basic 认证，单文件默认上限约 50 MB，WebClient 服务已被官方标为弃用 |

## 状态窗口与账号

- 插件窗口里有启动状态、自动发现与防休眠的状态说明、最近连接的客户端和提示横幅。
- 账号（默认用户名 `eagle`）和密码都在「设置」里填；密码留空表示不要求认证。
- **自动发现（Bonjour）**：Infuse 等 App 的 WebDAV 发现列表里会出现这台 Mac，不用手输地址。Finder 的「网络」不会列出 WebDAV，Finder 仍要按 ⌘K 输入地址。
- **阻止休眠**：有文件在传输或播放时（读取、上传、复制、移动）自动阻止 Mac 休眠，传输结束约 1 分钟后放开。只是挂着 Finder 的卷或浏览目录不会阻止休眠。
- Eagle 在等你确认「重复添加提示」时，窗口顶部会出现黄色提示，并用 Eagle 通知提醒一次。

## 目录结构

- 根目录列出所有顶层文件夹，另有两个虚拟目录：
  - `@未分类`：不属于任何文件夹的素材，可写。
  - `@标签`：按标签浏览素材，**只读**（可复制出来，不能往里写、改、删）。可在配置里关闭。
- 一个素材属于多个文件夹时，在每个文件夹里各出现一次。

## 和普通网盘不同的地方

- **删除素材**：整个素材进入 Eagle 回收站；如果它同时在多个文件夹里，会从所有文件夹里消失。不提供永久删除。
- **文件夹不能删**：Eagle 的接口没有删除文件夹的方法，请求返回 403，要在 Eagle 里删。可以新建、改名、移动文件夹。
- **同名素材**：同一目录下重名时，后来的会加上「 ~ID末6位」后缀，例如「海报 ~XTXR7I.jpg」；原来带后缀的旧路径之后仍能访问。
- **复制的含义**：名字不变、复制到另一个文件夹，只是让素材同时属于那个文件夹，不多出一份文件；复制时改名、或在同一目录内复制，才真正复制出一份新素材（带上标签、星级、注释）。**如果内容与库里已有文件完全相同，Eagle 会弹出「重复添加提示」，需要在 Eagle 里点一下确认，新素材才会出现。**
- **扩展名不能改**：重命名只能改文件名部分，改扩展名返回 403。
- **没有扩展名的文件不能上传**：Eagle 不识别，返回 415。其他任意扩展名都可以导入。
- **文件名里的特殊字符**：Eagle 导入时会删掉 `: ? * " < > \ | %`、emoji 和部分符号。服务按同样规则匹配，所以用原名仍能读回、覆盖和改名；但文件名只有 emoji 之类、删完为空的，会返回 400。
- **标签、星级、注释**：Finder 改不了。支持 WebDAV 属性的客户端可以通过自定义属性（命名空间 `urn:eagle-webdav:ns`：`tags`、`star`、`annotation`、`url`）读写，日常仍建议在 Eagle 里改。
- **同步延迟**：在 Eagle 界面里的改动，客户端下一次请求时（最多约 1.5 秒后）就能看到。在 Eagle 里用「替换文件」换成同样大小的内容，客户端缓存可能察觉不到。
- **Finder 的临时文件**：`.DS_Store`、以 `._` 开头的文件、`.Spotlight-V100` 等会被服务端吸收到临时区，不会出现在 Eagle 里，重启或切换资源库后丢弃。
- **Finder 拷贝新文件**：先写一个 0 字节占位，再加锁、写入真正的内容；服务只在收到内容后才导入，不会产生空素材。

## 安全建议

- 只在家里的局域网使用：默认只放行回环、10/8、172.16/12、192.168/16、169.254/16 和 IPv6 内网地址的来源；同一来源连续认证失败 10 次会被封禁 10 分钟。
- 要从外网访问，不要直接暴露本服务，在前面加 Caddy 或 Nginx 做 HTTPS 和访问控制。
- 没设管理密码时，能连上服务的任何人都等同管理账号；对局域网开放前请自行决定是否设置密码。

## 已知限制

- 大资源库（几十万素材）的性能尚未实测；协议层在 20 万条的假数据上列 2 万条的目录约 0.1 秒，真正的耗时取决于 Eagle 自身的查询。
- 「未分类」和「@标签」每次缓存失效后需要重新向 Eagle 查询，大库里首次打开会慢一些。
