# Eagle WebDAV 使用指南

Oct 11, 2026 · @Turi

插件实现后，Eagle 开着的 Mac 会提供 WebDAV 服务，Finder、Infuse、rclone 等客户端可以像访问网盘一样读写 Eagle 资源库。以下步骤由设计文档推演而来，尚未在真机上实测。

## 安装与首次设置

1. 把 Eagle 升级到当前最新的 4.0 Build23；插件要求至少 Build12。
2. 在 Eagle 的「开发者选项」里，把打包好的 `plugin/` 目录作为本地插件加载。后台服务插件随 Eagle 启动，本地使用无需上架审核。
3. 首次启动会弹出状态窗口，设置监听的局域网 IP、端口（默认 41600）、账号和密码。
4. macOS 防火墙若弹出提示，允许 Eagle 接受入站连接。
5. 之后只要 Eagle 开着，服务就在；Eagle 退出，服务随之停止；切换资源库时服务会短暂返回 503，几秒后恢复。

## 各设备怎么用

Mac 上用 Finder 读写，iPad 与 iPhone 用 Infuse 或第三方 WebDAV App，脚本用 rclone，Windows 不建议作主力。

| 设备或工具 | 推荐用法 | 注意事项 |
| --- | --- | --- |
| Mac Finder | 按 Command + K，输入 `http://Mac 局域网 IP:41600/`，填账号密码后挂载 | 拖入的文件会导入 Eagle，资源库里是一份副本，原文件仍在原处；改名、移动、复制会同步到 Eagle |
| iPad、iPhone 看影音 | 用 Infuse 连接，可拖进度条、续播 | Infuse 官方支持 WebDAV |
| iPad、iPhone 管文件 | 用提供文件提供者的第三方 WebDAV App，这样在「文件」App 里也能看到 | 「文件」App 的「连接服务器」原生似乎只支持 SMB，置信度中等；局域网地址可用 HTTP，外网地址需 HTTPS |
| rclone 与脚本 | 配置 WebDAV 远端，vendor 选 other，用 `rclone ls`、`rclone copy` | 可把 Eagle 按文件夹结构导出到磁盘做备份 |
| Windows | 不建议作主力 | 默认禁用 HTTP 上的 Basic 认证，单文件默认上限约 50 MB，WebClient 服务已被官方标为弃用 |

## 和普通网盘不同的地方

- **删除素材**：整个素材进入 Eagle 回收站；如果它同时在多个文件夹里，会从所有文件夹里消失。
- **文件夹不能删**：Eagle 的接口不提供删除文件夹，请求会返回 403，要删得回 Eagle 里操作。
- **同名素材**：同一目录下重名时，后来的会加上「 \~ID末6位」后缀，例如「海报 \~XTXR7I.jpg」。
- **复制的含义**：名字不变、复制到另一个文件夹，只是让素材同时属于那个文件夹，不会多出一份文件；复制时改名，或在同一目录内复制，才会真正复制出一份新素材。
- **扩展名不能改**：重命名时只能改文件名部分。
- **标签、星级、注释**：Finder 改不了，只能通过 WebDAV 自定义属性暴露给支持的客户端，日常仍在 Eagle 里改。
- **同步延迟**：在 Eagle 界面里的改动，WebDAV 客户端大约 5 到 60 秒后可见。
- **Finder 的临时文件**：`.DS_Store`、以 `._` 开头的文件会被服务端吸收，不会出现在 Eagle 里。

## 安全建议

- 只在家里的局域网使用，默认只放行私有网段的来源。
- 要从外网访问，不要直接暴露本服务，在前面加 Caddy 或 Nginx 做 HTTPS 和访问控制。
- 账号密码保存在 Eagle 的用户数据目录里，用 scrypt 哈希，不写进插件目录。

## 尚未验证的推测

以下几点要等 M0 实测探针才能确定，到时用法可能调整：

- 插件能否稳定监听局域网地址，以及防火墙是否拦截。
- 跨文件夹移动和复制是否真的生效，即给 `item.folders` 赋值后保存是否有效；若失败，这两类操作改为返回 403，或改用 Eagle 的 Web API V2 兜底。
- Finder 拷贝新文件时的实际请求顺序。
